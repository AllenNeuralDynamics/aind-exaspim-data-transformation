# End-to-End Data Flow Pipeline

## Overview

This diagram traces data from raw Imaris `.ims` files through compression and pyramid generation to the final OME-Zarr v3 store on S3. The pipeline is split across two responsibility domains: **Worker 0** handles one-time metadata tasks, and **all workers** (including Worker 0) handle compression.

## Pyramid Level Generation (Two Paths)

```mermaid
flowchart TD
    Decision{"translate_imaris_pyramid?"}
    
    Decision -->|"True (default)"| TranslatePath
    Decision -->|"False"| ComputePath
    
    subgraph TranslatePath["Path A: Translate Existing Imaris Pyramids"]
        T1["For level 1..4:<br/>data_path = /DataSet/ResolutionLevel {lvl}/…/Data"]
        T2["Partition level's shards across 64 workers<br/>(independent from base level)"]
        T3["process_single_shard() reads from<br/>Imaris pyramid level directly"]
        T4["Write to Zarr level store on S3"]
    end
    
    subgraph ComputePath["Path B: Recompute via TensorStore Downsample"]
        C1["create_downsample_levels()"]
        C2["For level 1..4 (sequential):"]
        C3["ts.open(downsample_spec)<br/>driver='downsample'<br/>base = level N-1<br/>method = 'mean'<br/>factors = [1,1,2,2,2]"]
        C4["downsampled_view.read()"]
        C5["dest_dataset.write(data)"]
    end

    T1 --> T2 --> T3 --> T4
    C1 --> C2 --> C3 --> C4 --> C5

    style TranslatePath fill:#e8f5e9,stroke:#1b5e20
    style ComputePath fill:#fff3e0,stroke:#e65100
```

**Path A** is preferred: reads pre-computed pyramids from the `.ims` file (already generated by microscope acquisition software), distributed across workers. **Path B** is a fallback that uses TensorStore's streaming downsample driver — sequential but memory-efficient.

## `run_job()` Complete Sequence

```mermaid
sequenceDiagram
    participant Entry as job_entrypoint()
    participant Job as ImarisCompressionJob
    participant W0 as Worker 0 Duties
    participant MS as Metadata Service
    participant S3 as S3 Bucket
    participant All as All Workers
    participant Dask as Dask LocalCluster
    participant HDF5 as Imaris File
    participant TS as TensorStore

    Entry->>Job: run_job()
    
    alt partition_to_process == 0
        Job->>W0: _upload_derivatives_folder()
        W0->>S3: aws s3 sync derivatives/
    end

    Job->>All: _get_sorted_stack_paths()
    All->>HDF5: glob **/*.ims → sort
    
    Job->>All: _build_global_shard_task_list()
    All->>HDF5: get_metadata_shape() per file
    All->>All: enumerate_shard_indices() per file → flat list
    
    Job->>All: partition_list(tasks, 64) → my_tasks
    
    Job->>Dask: LocalCluster(n_workers=4, threads_per_worker=1)
    
    loop For each file in my tasks_by_file
        All->>All: _process_file_shards(stack, shard_indices)
        All->>TS: create_scale_spec() → ts.open(create=True, open=True)
        
        loop For each shard in my_shard_indices
            All->>Dask: client.submit(process_single_shard, **task)
            Dask->>HDF5: read_block(slices)
            HDF5-->>Dask: numpy array
            Dask->>TS: store[slices].write(data)
            TS-->>S3: PutObject (shard file)
        end
        
        All->>All: as_completed(futures) → progress logging
    end

    loop Pyramid levels 1..4
        All->>All: Re-partition level shards across 64 workers
        All->>Dask: submit process_single_shard (reads ResolutionLevel N)
        Dask->>HDF5: read_block(level_N_slices)
        Dask->>TS: write(level_N_data)
    end

    alt partition_to_process == 0 or dask_client present
        All->>TS: write_ome_ngff_metadata() → zarr.json
    end

    Job-->>Entry: JobResponse(status_code=200)
```
